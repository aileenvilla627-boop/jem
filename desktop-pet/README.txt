DESKTOP PET (Windows)
=====================
A little pixel cat that walks along the bottom of your screen, on top of every
window and website. It only shows while the Claude app is open, and hides when
you close Claude.

START IT
  Double-click Start-Pet.bat

START IT AUTOMATICALLY EVERY TIME (recommended)
  Double-click Install-Autostart.bat once.
  From then on it runs quietly in the background and appears whenever Claude is open.

PLAY WITH IT
  Click the cat ............ pet it (hearts + purr)
  Drag the cat ............. pick it up and drop it
  Right-click the cat ...... Feed / Pet / Sleep / Wake up / Exit
  It walks, sits, naps, chases your mouse and gets hungry after a few minutes.

STOP IT
  Right-click the cat > Exit
  To remove it completely: double-click Uninstall.bat

ALWAYS SHOW IT (even without Claude)
  Edit Start-Pet.bat and add  -FollowApp ""  at the end of the powershell line.

If Windows shows "Windows protected your PC", click More info > Run anyway.
